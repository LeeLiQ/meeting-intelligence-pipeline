# 先看这一页 · START HERE

> 别慌。其它文件你**都不用主动读**。这套系统的设计就是：你每次只做一件事，剩下的交给 Claude。

## 你唯一要记住的一句话
每次坐下，打开这个 repo，对 Claude 说：

> **「Based on learning/progress.md, plan today's session. 我今晚大概 X 分钟，精力 🟢/🟡/🔵。」**

Claude 会读你的进度、决定今天学什么、给你一个刚好大小的任务，结束时帮你更新进度。
**你不用自己去读 map 或 plan。**

## 按"今晚的精力"选档（这点最重要）
累的时候别硬上完整 session。告诉 Claude 你是哪一档，它会裁剪：

| 档 | 时间 | 今晚做什么 | 写代码吗 |
|---|---|---|---|
| 🟢 累瘫 | 5–10 分钟 | 复述上次的 1 个概念 / 读一篇 note / 答 1 个问题 | 不用 |
| 🟡 一般 | 15–25 分钟 | 学 1 个概念 + 一个很小的练习 | 可有可无 |
| 🔵 有劲 | 45–60 分钟 | 完整 session：≤3 个概念 + 一个能跑的 deliverable | 写 |

🟢 的晚上**也算数**。保持手感，比赶进度重要。

## 这些文件是什么（扫一眼就行，别读）
- **progress.md** — 你的存档点。**Claude 读它，不是你读。**
- **01_map.md / project_plan.md** — 参考书，不是读物。需要时 Claude 替你查。
- **notes/** — 你学懂一个概念后写的一小篇（Claude 帮你起草）。这几乎是你唯一会"产出"的东西。
- **exercises/ · reviews/** — 练习和阶段小测，Claude 到点会给你。
- 其它（00_goal、sources、README、claude-extras）— 背景，想了解再看。

## English (same thing, short)

Don't worry — you never need to read the other files. Each session you do one thing; Claude does the rest.

**The only sentence to remember**, every time you sit down:

> "Based on learning/progress.md, plan today's session. I have about X minutes tonight, energy 🟢/🟡/🔵."

**Pick a tier by energy** (the important part):
- 🟢 wiped (5–10 min): recall one concept / read a note / answer one question. **No code.**
- 🟡 ok (15–25 min): one concept + a tiny exercise. Code optional.
- 🔵 fresh (45–60 min): full session, ≤3 concepts + one runnable deliverable.

A 🟢 night still counts. Consistency beats speed.

**The files** (glance, don't read): `progress.md` is read *by Claude*, not you; `01_map.md` / `project_plan.md` are reference, not reading; `notes/` is the one thing you produce (Claude drafts it); `exercises/` & `reviews/` arrive when it's time.

**Tonight:** open the repo → say the sentence → add your minutes + tier. That's it.
